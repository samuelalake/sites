# Sites

Shared home for Samuel's product websites.

## Starting point

`apps/things-reference` is the preserved Things site import. Treat it as a fidelity reference and foundation, not as Rem or Trove product copy.

## Planned sites

- `apps/rem`
- `apps/trove`
- `apps/composa`

Each product can be deployed independently while sharing reference material and, later, common components where that genuinely helps.

## Run the reference

```sh
cd apps/things-reference
pnpm install
pnpm dev
```
